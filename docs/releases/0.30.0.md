# EWM 0.30.0 — большое обновление редактора и калибровки

## Редактор F5

- Компактные метки: круг для нажатий, ромб для MOBA-навыка, квадрат для отмены.
- Геометрия раскрывается только у выбранного элемента. Центр героя снова обозначен крестом.
- Настройки открываются через ПКМ у курсора. Убраны отдельные плавающие кнопки настроек.
- Компактные русские настройки с закрытием крестиком, сохранены перетаскивание, радиусы и переназначение клавиш.
- Искусственная точка нажатия и реальный центр джойстика показаны раздельно; круг расположен на реальном центре.

## Автоматическая геометрия

«АвтоГеометрия» удерживает виртуальный палец неподвижно и получает три снимка игрового изображения. Центр уточняется по малому неподвижному кругу, внешний обод задаёт размер с запасом 5%. После снимков палец освобождается до длительного анализа. Неподтверждённое обнаружение не меняет настройки. Результат можно отменить через Ctrl+Z.

«Автопоиск Урануса» помогает определить центр героя по игровому указателю. Общий центр можно подправить во время любой калибровки стрелками: 1 пиксель Android, Shift — 10; ПКМ ставит центр непосредственно.

## Экспериментальная калибровка

- Переключатель «Оригинал / Экспериментальная» сохраняет доступ к прежним калибровкам.
- Центр героя и экспериментальный угол общие для всех профилей одного точного разрешения Android.
- Отдельные режимы «Навык с дальностью / Навык направления».
- Дальность: **12 точек = 4 направления**, **24 = 8**, **48 = 16**; в каждом направлении измеряются три отклонения. 24 и 48 отдельно измеряют нижние диагонали.
- «Конец за экраном» пропускает невидимые концы. Если минимальное отклонение слишком велико, оно уменьшается вдвое до появления видимого конца.
- «Разгон у края» позволяет достичь полной дальности у обрезанного края экрана. В этой зоне прицел намеренно расходится с курсором. Если видимых данных мало, зона расширяется.
- Измерения, пропуски и действительные отклонения записываются в журнал для дальнейшего анализа.

Экспериментальная дальность пока использует интерполяцию между измеренными направлениями. Точность зависит от игровых измерений; идеальная точность на всех героях и камерах не обещается. Старые 12-точечные данные совместимы, для дополнительных направлений нужна новая калибровка дальности.

## Передвижение и ввод

- «Оригинальный / Экспериментальный» режимы MOBA-передвижения. Эксперимент использует общий угол для мыши и WASD, сохраняя правила клика, удержания и длительности маршрута.
- ЛКМ во время передвижения — отдельное удерживаемое касание с перетаскиванием и отпусканием. Можно пользоваться миникартой и свайпать, пока персонаж идёт по команде ПКМ.
- Скорость отмены навыка задаётся числом в миллисекундах вместо фиксированных пресетов.
- Удалён плохо работающий ранний просчёт.

## Живая разработка

Добавлены режим разработки, наблюдение за исходным QML, ручная перезагрузка UI и локальный инструмент dev-control. Изменения QML можно проверять без перезапуска игры; изменения C++ требуют перезапуска EWM. Режим разработки включается явно и по умолчанию выключен.

## Как обновиться

В главном окне EWM: **⚙ → Обновиться**. После успешной установки перезапустите EWM с обычного ярлыка. Установщик выбирает x86_64 или ARM64, проверяет SHA-256 и заменяет установку целиком. Профили и пользовательская конфигурация сохраняются.

## Проверки

Нативные тесты детектора, изолированный Wayland-клиент, удержание/перетаскивание/отпускание касаний, исходная и экспериментальная калибровки, 12/24/48 точек, профили/багаж, отмена и undo, журнал измерений и перезагрузка UI. Часть поведения проверялась в живой игре; новые варианты дальности и независимый ЛКМ пока подтверждены изолированными проверками и требуют игрового тестирования.
