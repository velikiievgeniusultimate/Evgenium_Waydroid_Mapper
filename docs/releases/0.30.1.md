# EWM 0.30.1 — исправление F11

- F11 переключает только полноэкранный режим EWM.
- Нажатие, отпускание и автоповтор F11 больше не передаются в Waydroid, в том числе в редакторе маппинга.
- Убрана дублирующая QML-комбинация; повторное удержание клавиши не переключает режим многократно.

## Как обновиться

В главном окне: **⚙ → Обновиться**. После установки перезапустите EWM с обычного ярлыка. Профили и настройки сохраняются.

## Проверки

Сборка и нативный тест обработки ввода: вход и выход из полного экрана, поглощение нажатия, отпускания и автоповтора в игровом режиме и редакторе. GitHub также запускает полный набор тестов для x86_64 и ARM64 перед публикацией архивов с SHA-256.
